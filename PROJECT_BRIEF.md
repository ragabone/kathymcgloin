# PROJECT_BRIEF.md

## Project
**Website for the novel _Second Chances by the Sea_**

Author: **Kathy McGloin**

This project is a simple, elegant promotional website for Kathy McGloin's novel _Second Chances by the Sea_.

The website should be lightweight, responsive, easy to maintain, and visually consistent with the existing book cover and launch artwork.

---

## Book

### Title
**Second Chances by the Sea**

### Author
**Kathy McGloin**

### Setting
The novel is centred around **Bundoran, County Donegal, Ireland**, with a Belfast backstory.

The coastal setting, including the **Fairy Bridges**, is an important part of the book's identity and should influence the website's visual design.

### Synopsis / Promotional Copy
Use the following copy unless instructed otherwise:

> After a devastating betrayal shatters the life she thought she was building in Belfast, Erin escapes to the seaside town of Bundoran on Ireland’s west coast, hoping only for a fresh start and a little peace.

Further synopsis text can be added later.

**Date:** Wednesday, September 9, 2026

## Website Goals

The website should:

1. Introduce the novel.
2. Present the book cover prominently.
3. Provide a concise synopsis.
4. Promote the book launch.
5. Introduce Kathy McGloin as the author.
6. Highlight Bundoran and the west-coast Irish setting.
7. Provide information on where the book can be purchased.
8. Provide contact and/or social-media links.
9. Work especially well on mobile phones.
10. Be simple enough to maintain without a CMS.

## Visual Direction

The design should match the existing book artwork.

### Mood
- Romantic
- Coastal
- Warm
- Calm
- Contemporary
- Irish seaside atmosphere

Avoid making the website look overly corporate.

### Colour Direction
Use colours inspired by the existing cover:
- Coastal / sky blues
- Soft sea tones
- Warm sunset tones
- White / cream backgrounds where appropriate
- Subtle red accents derived from the existing launch artwork

Do not introduce strong unrelated colours unless there is a clear design reason.

### Typography
Typography should feel suitable for contemporary romantic fiction.

Use:
- A distinctive serif or elegant display font for headings/book title
- A highly readable font for body copy

Keep the number of fonts limited.

### Layout
Prefer:
- Generous whitespace
- Large visual hero area
- Strong book-cover presentation
- Soft transitions between sections
- Comfortable reading widths
- Mobile-first responsive layout

Avoid:
- Dense navigation
- Excessive animation
- Carousels unless genuinely useful
- Heavy UI frameworks or unnecessary components

## Technical Direction

Preferred stack:

- **Vue 3**
- **Vite**
- JavaScript unless TypeScript provides a clear benefit
- Standard responsive CSS

Keep dependencies minimal.

The site should be suitable for deployment as a static website.

Likely hosting options include:
- Render
- Netlify
- Cloudflare Pages

Deployment does not need to be implemented until requested.

---

## Development Principles

When working on this project:

1. Preserve the visual identity of the book.
2. Prioritise mobile usability.
3. Keep the implementation simple.
4. Do not invent factual content about the author, book, retailers, reviews, awards, or availability.
5. Use placeholders where information has not yet been supplied.
6. Keep content easy to edit.
7. Prefer semantic HTML and accessible components.
8. Ensure reasonable colour contrast and keyboard accessibility.
9. Optimise large images before production deployment.
10. Avoid unnecessary backend services.
